Backup configurazione

Le credenziali sono salvate nel localStorage del browser corrente e non sono disponibili su altri PC o browser. Esporta un file wego-config.json da importare su ogni nuovo dispositivo. Conservalo in modo sicuro — contiene le chiavi API.

Supabase — Database Apri dashboard
1Crea account su supabase.com

Vai su supabase.com, crea un account gratuito e un nuovo progetto.

2Esegui lo schema SQL

Pannello Supabase → SQL Editor → New query, incolla e lancia:

3Copia le credenziali API

Project Settings → API. Copia Project URL e anon public key.

Firebase — Push Notifications Apri console
1Crea progetto Firebase

Vai su console.firebase.google.com, crea progetto e aggiungi una Web App.

2Abilita Cloud Messaging

Project Settings → Cloud Messaging → genera chiavi VAPID (Web Push certificates).

3Copia le credenziali

Project Settings → General → Your apps → SDK setup and configuration.

Da Project Settings → Cloud Messaging → Web Push certificates
Deployment — Vercel Apri dashboard
1Push su GitHub

Carica la cartella del progetto su un repository GitHub.

2Importa su Vercel

vercel.com → Add New Project → seleziona il repo → framework: Other → deploy.

3Configura il dominio

Vercel assegna un URL *.vercel.app. Le PWA richiedono HTTPS — fornito automaticamente.
