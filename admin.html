Firebase — Push Notifications Apri console
1 Crea progetto Firebase

Vai su console.firebase.google.com, crea un nuovo progetto (gratuito), poi aggiungi una Web App al progetto.

2 Abilita Cloud Messaging

Nel pannello Firebase → Project Settings → Cloud Messaging. Genera una coppia di chiavi VAPID (Web Push certificates).

3 Copia le credenziali

Project Settings → General → sezione Your apps → SDK setup and configuration → copia i valori.

Dalla sezione Web Push certificates in Project Settings → Cloud Messaging
Deployment — Vercel Apri dashboard
1 Push su GitHub

Carica la cartella del progetto su un repository GitHub (pubblico o privato).

2 Importa su Vercel

Su vercel.com → Add New Project → seleziona il repository GitHub → framework: Other → deploy. WeGo non richiede build.

3 Configura il dominio

Vercel assegna automaticamente un URL *.vercel.app. Per un dominio custom: Project Settings → Domains. Le PWA richiedono HTTPS — Vercel lo fornisce automaticamente.

Nota: il file vercel.json con i headers PWA viene generato automaticamente dal pulsante sotto.
